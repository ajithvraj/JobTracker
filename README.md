JobTracker – Job Application Tracking System
Overview

JobTracker is a personal job application tracking system designed to help developers manage, organize, and follow up on job applications efficiently.

The application allows users to track job applications across multiple platforms (LinkedIn, Indeed, Naukri, referrals, email, etc.), manage application statuses, schedule follow-ups, and maintain a clear overview of their job search process.

This project is built with ASP.NET Core following Clean Architecture principles, with a modern frontend (React) and scalable backend design.

Why I Built This Project

While applying for multiple roles, I realized there was no simple, developer-focused tool to:

Track job applications in one place

Avoid missing follow-ups

Clearly see application progress

Practice real-world full-stack architecture

So I built JobTracker as both:

A real personal productivity tool

A portfolio-grade full-stack application
